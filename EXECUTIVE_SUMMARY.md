# Executive Summary

Experiment 67 is a finite certified benchmark for deterministic two-agent binary mechanisms. It checks all 1,296 allocation/payment tables under DSIC, ex-post IR, feasibility, exact budget balance, anonymity, bounded fairness, and two-agent coalition strategyproofness. Exactly four tables survive; an independent checker returns the identical frontier. No accepted table strictly improves the anonymous-OR baseline in uniform welfare, and bounded held-out/adversarial audits pass. This is a reproducible finite result, not a novel or general mechanism-design theorem.
