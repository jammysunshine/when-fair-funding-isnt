# Three-agent extension

This additive extension broadens Experiment 67 from two to three agents while
keeping exact finite verification. Reports and alternatives are binary;
utilities are `m * 1{type = chosen alternative}`; deterministic direct rules
use integer payments in `{-2,-1,0,1,2}`. The enumerated class is **all
anonymous, pointwise exactly budget-balanced tables in that grid**. Anonymity
reduces the space to four count-based choices, three feasible payment rows for
count one, and three for count two: `2^4 * 3 * 3 = 144` candidates.

The frozen acceptance predicate is DSIC, ex-post IR, feasibility, exact budget
balance, anonymity, truthful utility spread at most one, and no profitable
deviation by any nonempty coalition (outsiders' reports fixed). Neutrality is
audited but not required. The baseline is zero-transfer three-agent majority.

Results from the exact run:

- 144/144 candidates were generated by both implementations.
- Both independent frontiers contain exactly 5 tables: constant 0, OR,
  majority, AND, and constant 1.
- No accepted table has a nonzero transfer.
- Majority has expected allocative welfare `2.25` under uniform profiles, the
  pointwise maximum for unit values; no accepted mechanism improves it.
- Independent adversarial confirmation across all profiles, all nonempty
  coalitions, and magnitudes `0,1,2` has zero failures.

Run from the repository root:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/run_three_agent_extension.py
python3 scripts/verify_three_agent_certificates.py
```

Machine-readable evidence is in
`artifacts/experiment_67_three_agent_results.json`,
`artifacts/experiment_67_three_agent_certificate.json`, and
`artifacts/three_agent_frontier.csv`; the plot is
`reports/three_agent_frontier.svg`.

This is a stronger finite artifact and negative frontier result, not a claim
about unrestricted three-agent mechanisms, continuous values, randomized
rules, or real-world deployment.
